## Reporting a Vulnerability

We take the security of FastKitty seriously. If you believe you have discovered a security vulnerability in FastKitty, please report it responsibly.

### How to Report

**Please DO NOT report security vulnerabilities through public GitHub issues.**

Instead, please report vulnerabilities by:
- Using GitHub's **Private Vulnerability Reporting** feature directly on the repository under the **Security** tab.
- Or sending an email to `abhilashmohanram@gmail.com` with the subject `[SECURITY] FastKitty Vulnerability Report`.

Please include the following details in your report:
1. Type of issue (e.g., tenant data leak, SQL injection, auth bypass, buffer overflow).
2. Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
3. Affected versions and environments.
4. Any potential mitigations or remediation patches if you have one.

### Response Timeline
- You will receive an acknowledgment of your report within 48 hours.
- We will provide a timeline for assessing the issue and preparing a fix.
- Once a patch is released, we will publicly disclose the vulnerability and credit you for the responsible disclosure.
